# CLASS QUIZ - GAME DESIGN DOCUMENT

## Fast-Paced Multiple Choice Battles for JHS English

-----

## 🎮 GAME OVERVIEW

**Game Name:** Class Quiz

**Type:** Competitive Multiple Choice Quiz Battle

**Format:** Kahoot-style fast-paced team competition

**Duration:** 15-25 minutes per session

**Players:** Whole class (teams or individuals)

**Purpose:** Review grammar, vocabulary, and comprehension through exciting competition

-----

## 🎯 CORE GAME MECHANICS

### Game Flow

```
1. SETUP (2 minutes)
   ├─ Teacher selects quiz (grade + grammar point)
   ├─ Students join game with names/team names
   └─ Display game code for student devices (optional)

2. QUESTION ROUND (10-20 minutes)
   ├─ Display question + 4 answer choices
   ├─ Timer starts (10-30 seconds depending on difficulty)
   ├─ Students select answer on screen/device
   ├─ Timer ends, answers locked
   ├─ Reveal correct answer with explanation
   ├─ Show scoreboard update
   └─ Repeat for 10-20 questions

3. FINAL RESULTS (3 minutes)
   ├─ Display final leaderboard
   ├─ Crown winner(s)
   └─ Show statistics (accuracy, speed, etc.)
```

## 🏆 SCORING SYSTEM

### Points Calculation

**Base Points:**

- Correct Answer: 1,000 points
- Wrong Answer: 0 points

**Speed Bonus:**

- Answer in first 5 seconds: +500 bonus
- Answer in 6-10 seconds: +300 bonus
- Answer in 11-15 seconds: +100 bonus
- Answer after 15 seconds: No bonus

**Streak Bonus:**

- 3 correct in a row: +200 bonus
- 5 correct in a row: +500 bonus
- 10 correct in a row: +1,000 bonus

**Example:**
Student answers correctly in 7 seconds with 2-answer streak:

- Base: 1,000
- Speed: +300
- Total: 1,300 points

## 🎲 GAME MODES

### Mode 1: Team Battle (Default)

- Class divided into 4-6 teams
- Each team has a device or raises hand for answer
- Team points combined
- Encourages collaboration

### Mode 2: Individual Race

- Each student answers on own device
- Personal leaderboard
- Top 3 individuals win
- Good for 1:1 device environments

### Mode 3: Survival Mode

- Start with all students standing
- Wrong answer = sit down and eliminated
- Last person/team standing wins
- No devices needed - students show color cards

### Mode 4: Lightning Round

- 5-second timer per question
- 20 rapid-fire questions
- Tests quick thinking
- High energy finale

### Mode 5: Boss Battle

- Teams face increasingly difficult questions
- Each “level” has 3 questions
- Must get 2/3 correct to advance
- Reach final boss for bonus points

## 📚 QUESTION STRUCTURE

### Question Types

**Type 1: Fill in the Blank**

```
Question: "I ___ to school yesterday."
A) go
B) goes
C) went ✓
D) going

Grammar: Past Simple
Difficulty: Easy
Time: 15 seconds
```

**Type 2: Error Correction**

```
Question: "Find the mistake: She don't like apples."
A) She → He
B) don't → doesn't ✓
C) like → likes
D) apples → apple

Grammar: Simple Present (negative)
Difficulty: Medium
Time: 20 seconds
```

**Type 3: Best Answer**

```
Question: "Which sentence is correct?"
A) I am agree with you.
B) I agree with you. ✓
C) I agreeing with you.
D) I am agreeing with you.

Grammar: Stative verbs
Difficulty: Medium
Time: 20 seconds
```

**Type 4: Meaning Match**

```
Question: "I have lived here for 5 years." What does this mean?
A) I lived here 5 years ago and moved.
B) I started living here 5 years ago and still live here. ✓
C) I will live here for 5 years.
D) I want to live here for 5 years.

Grammar: Present Perfect (duration)
Difficulty: Hard
Time: 25 seconds
```

**Type 5: Word Order**

```
Question: "Put in correct order: went / yesterday / I / shopping"
A) I went shopping yesterday ✓
B) Yesterday I shopping went
C) I shopping went yesterday
D) Went I yesterday shopping

Grammar: Past Simple (sentence structure)
Difficulty: Easy
Time: 20 seconds
```

**Type 6: Vocabulary in Context**

```
Question: "The movie was ___. I fell asleep."
A) exciting
B) boring ✓
C) interesting
D) amazing

Grammar: Adjectives
Difficulty: Easy
Time: 15 seconds
```

## 📊 CONTENT ORGANIZATION

### Quiz Sets Structure

Each quiz set contains:

- **20 questions** (perfect for one class period)
- **Mix of difficulties**: 8 Easy, 8 Medium, 4 Hard
- **One grammar focus** or mixed review
- **Progressive difficulty** (easy → medium → hard → mixed)

### Annual Question Bank

**Per Grade Level:**

- 40 weeks × 2 quizzes per week = **80 quiz sets**
- 80 sets × 20 questions = **1,600 questions per grade**
- **Total: 4,800 questions across 3 grades**

**Organization by Grammar Point:**

**Grade 1 Example:**

```
Quiz Set G1-W01-A: Be Verbs (Introduction)
├─ Questions 1-8: Easy fill-in-blanks
├─ Questions 9-16: Medium error correction
└─ Questions 17-20: Hard mixed application

Quiz Set G1-W01-B: Be Verbs (Practice)
├─ Questions 1-8: Easy questions different from Set A
├─ Questions 9-16: Medium questions
└─ Questions 17-20: Hard questions
```

## 📈 DIFFICULTY PROGRESSION

### Within Each Quiz Set:

- Questions 1-8: Foundation (Easy) - Build confidence
- Questions 9-16: Application (Medium) - Test understanding
- Questions 17-20: Challenge (Hard) - Stretch thinking

### Across the Year:

- **Weeks 1-10:** More easy questions (60% easy, 30% medium, 10% hard)
- **Weeks 11-30:** Balanced mix (40% easy, 40% medium, 20% hard)
- **Weeks 31-40:** More challenging (30% easy, 40% medium, 30% hard)
